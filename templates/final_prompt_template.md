# Final Prompt Template（skill 输出时会自动填充；用户无需编辑）

填写前先按 SKILL.md 的“画幅规则”确定参数：默认或仅指定竖版时为竖版 / 3:4 / 1080 / 1440；仅指定横版时为横版 / 4:3 / 1440 / 1080。用户明确指定的比例或尺寸优先。输出最终提示词时移除此说明，填完下面的占位符，并确认方向、比例与像素尺寸一致。

生成一张严格 {ORIENTATION} 封面图，整张输出画布宽:高（width:height）= {ASPECT_RATIO}，目标尺寸 {WIDTH_PX} 像素宽 × {HEIGHT_PX} 像素高（安全边距 6–8%，不要裁切标题/人脸/主视觉）。该比例约束整个图像文件，不能用其他比例画布包裹目标比例的海报。
固定系列版式：顶部标题；右下真人（同一人脸）；主题主视觉集中在左下与中下区域；背景纹理随主题变化。

- 关键词高亮策略：{KEYWORD_HIGHLIGHT_STRATEGY}

- 轻弧排版策略：{KEYWORD_ARC_STRATEGY}
  - 关键词所在行/标签沿“很轻微弧线”排布（左下→右上微上扬），不可夸张
- 识别锚点（可选）：{ANCHOR_ICON}

【人物（右下角）】

- 要求：脸清晰、主光干净、表情具有感染力（掌控/灵光一闪）

【主题主视觉（自由发挥，必须贴题）】

【主题配色与背景（不固定蓝色）】
